# E-Commerce Performance Analytics Project

## Project Overview

An interactive data analytics dashboard analyzing E-commerce giants: Amazon, eBay, and Alibaba.

The project uses **Python, Pandas, Plotly, and Dash** to perform data analysis and create interactive visualizations.
